# ShopKart Brasil — Delivery & Customer Experience Analytics

A full-cycle analytics project investigating delivery reliability and customer experience using the public Olist Brazilian e-commerce dataset.

The project covers:

- Business requirements definition
- Data modeling
- Automated Python ETL pipeline
- PostgreSQL analytics
- 12+ SQL analyses using CTEs, window functions, and conditional aggregation
- Statistical validation
- 5-page interactive Power BI dashboard

## Key Finding

A key finding was that the **delivery-promise buffer had the strongest observed relationship with late-delivery rate** among the factors analyzed.

Seller handling time remained relatively stable, while product weight showed a weaker relationship with late delivery.

The analysis also quantified the relationship between delivery delays and customer review scores.
